## セッション開始（引き継ぎ）
```
AGENTS.md と AI/STATUS.md を読んで現状を把握し、
STATUS.md の「次にやること」の先頭タスクから作業を開始してください。
着手前に、作業方針を1〜2行で確認させてください。
```

## 要件定義書の作成
```
Docs/01_concept.md を読み、Docs/02_requirements.md に要件定義書のドラフトを作成してください。
情報が不足している点は、まとめて質問してください。
```

## 設計書の作成
```
Docs/02_requirements.md と Sandbox/ での検証結果を踏まえ、
Docs/03_design.md に設計書を作成してください。
画面構成・データモデル・主要な処理フローを含めてください。
```

## スタック鮮度チェック（新規プロジェクト開始時）
```
AGENTS.md の「標準技術スタック」を確認し、現時点でも妥当か評価してください。
更新すべき点があれば、理由とともに提案してください。
採用したら AGENTS.md と AI/DECISIONS.md への反映もお願いします。
```

## セッション終了
```
ここまでの作業内容を AI/STATUS.md に反映してください。
設計判断があった場合は AI/DECISIONS.md への追記も忘れずに。
```

```
以下の内容を Docs/XX.md として保存してください。
（チャットで作成した内容を貼り付け）
```
